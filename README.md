  #  Requisitos No Funcionales y Funcionales

RNF de la entrevista:

- El sistema debe ser seguro y proteger los datos personales de los pasajeros.
- 
- El sistema debe responder rápidamente a las consultas y reservas.
- 
- El sistema debe estar disponible mayor parte del tiempo.
- 
- El sistema debe ser fácil de usar para el personal y los pasajeros.
- 
- El sistema debe permitirse acceso según roles, por ejemplo: admin, operador, cajero.
- 
- El sistema debe mantener integridad en los datos de reservas, vuelos y pagos.
- 
- El sistema debe poder soportar varios usuarios al mismo tiempo.

- El sistema debe ser compatible con computadoras usadas en la empresa
- 
- El sistema debe generar información confiable y actualizada
- 
- El sistema debe permitir respaldo de la información para evitar pérdida de datos.
